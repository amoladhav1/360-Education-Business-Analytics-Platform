## 🚀 Project Overview

The **360 Education Business Analytics Platform** is a business intelligence portfolio project focused on organizing business data and presenting it through interactive analytical reports.

The project demonstrates how business data can be prepared, analyzed, and visualized to help stakeholders monitor performance, identify trends, and make informed decisions.

The intended education-business use case covers key operational areas such as marketing, sales, student admissions, placements, and finance. These areas can be analyzed together to provide management with a broader understanding of business performance.

> **Project note:** The currently committed assets include a Power BI report named `Final_Project1.pbix`, an Excel dataset named `UrbanNest_RealEstate.xlsx`, and supporting real-estate documentation. The implementation should be aligned with the education-business description as the relevant education datasets and reports are added.

## 🎯 Business Problem

Organizations need reliable and timely information to understand their performance. When data is maintained across different files and departments, generating a consolidated view of business operations becomes difficult.

In an education and IT training business, management may need answers to questions such as:

- Which branches generate the highest revenue?
- Which marketing channels attract the most leads?
- How effectively are leads converted into student admissions?
- Which courses attract the most enrollments?
- How does placement performance vary across courses and branches?
- Are revenue and admission targets being achieved?
- Which business areas require management attention?

A centralized business intelligence solution can help answer these questions through consistent metrics, interactive filtering, and visual reporting.

## 🎯 Project Objectives

- Consolidate relevant business information for analysis.

## 🔄 Project Workflow

The project follows a typical business intelligence workflow.

```text
Source Data
    |
    v
Data Understanding
    |
    v
Data Cleaning & Transformation
    |
    v
Data Modeling & Relationships
    |
    v
DAX Measures & KPI Development
    |
    v
Interactive Power BI Dashboards
    |
    v
Business Insights & Decision Support
```

### 1. Data Understanding

- Review the source files and available tables.
- Understand column names, data types, and business definitions.
- Identify the analytical questions the report should answer.

### 2. Data Cleaning and Transformation

- Review missing and duplicate values.
- Standardize inconsistent text values.
- Correct column data types.
- Rename columns for clarity.
- Prepare the data for reliable analysis.

### 3. Data Modeling

- Identify relationships between relevant tables.
- Define appropriate keys and relationship cardinality.
- Validate filter behavior between related tables.
- Organize the model for maintainable reporting.

### 4. DAX and KPI Development

- Create reusable measures for important business metrics.
- Apply appropriate aggregation and filter context.
- Calculate ratios, percentages, and performance indicators.
- Validate calculations against the underlying source data.

### 5. Dashboard Development

- Select visuals based on business requirements.
- Organize information using appropriate layouts.
- Add slicers and interactive filtering where applicable.
- Use consistent titles, labels, and number formats.

### 6. Analysis and Validation

- Compare results across relevant business dimensions.
- Investigate unusual trends and performance differences.
- Validate totals and measures.
- Present findings in a format that stakeholders can understand.

## 💻 Getting Started

### Prerequisites

Before exploring the project, ensure that you have:

- A Windows computer
- [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/)
- [Microsoft Excel](https://www.microsoft.com/microsoft-365/excel) or a compatible spreadsheet application
- Git, if you want to clone the repository

### Step 1: Clone the Repository

Open a terminal or Command Prompt and execute:

```bash
git clone https://github.com/amoladhav1/360-Education-Business-Analytics-Platform.git
```

### Step 2: Open the Project Folder

```bash
cd 360-Education-Business-Analytics-Platform
```

### Step 3: Open the Power BI Report

Open the following file using Power BI Desktop:

```text
Final_Project1.pbix
```

### Step 4: Configure the Data Source

If Power BI cannot locate the source data:

1. Open **Transform data** or the data source settings.
2. Locate the relevant source file path.
3. Update it to match the downloaded project folder.
4. Apply the changes and refresh the data.

### Step 5: Explore the Report

Review the available report pages, visuals, filters, relationships, and DAX measures to understand the analytical approach used in the project.
